# Entregável 2 — Execução nas DuckDuckGo Privacy Test Pages

**Ambiente:** Firefox 156.0.1 (macOS), perfil limpo criado pelo harness `tools/capture_ddg.py`, com as
proteções nativas do Firefox desligadas (Enhanced Tracking Protection, partição de cookies/estado de rede,
query stripping, bounce tracking protection, resistFingerprinting) para que o plugin observe o tráfego
sem interferência do navegador. Plugin carregado como extensão temporária. Data: 28–29/09/2026.

Para cada página: o **resultado esperado** é o que a própria página reporta (texto na tela e, quando
existe, o JSON gerado pelo botão "Download the result", salvo em `evidencias/ddg/NN-*-resultado-pagina.json`).
O **resultado do plugin** vem do JSON exportado pelo plugin (`evidencias/ddg/NN-*.json`). O print
`evidencias/ddg/NN-*.png` mostra a página de teste (esquerda) e o relatório do plugin para aquela aba (direita).

## Síntese

- **Cobertura:** o plugin reproduziu os resultados da página em todos os testes de rastreadores (1–5), storage (6), fingerprinting (8–9), bounce (10) e query parameters (11), e produziu o comportamento correto em 12.
- **Divergências estruturais** (não são erros de detecção): o plugin é um *observador*, não um *bloqueador por padrão* — não aplica surrogates (4), não remove query parameters (11) e não particiona storage (7). O bloqueio existe apenas pela lista personalizada (5b).
- **Limite de arquitetura:** relatório por aba. Testes que abrem janelas secundárias (7) espalham a evidência em dois relatórios; o plugin registra a janela aberta para permitir a correlação.
- **Limite de instrumentação:** WebSocket só é visto pelo hook do construtor quando o handshake não passa pelo `webRequest` (5a); canais de persistência indiretos (`window.name`, `history`, cache HTTP) não são instrumentados (6).
